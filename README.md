# DNS filter for [AdBlock-Fast](https://docs.mossdef.org/adblock-fast/)
- [Script to update AdBlock-Fast filters, and upload the configuration and compiled DNS filter to a Git repository](bin/update-and-upload-adblock-fast-dnsfilter), allowing to keep a history of changes and distribute the latest compiled filter to other machines
- [Configuration for AdBlock-Fast](uci/adblock-fast) in [OpenWrt](https://openwrt.org/)
- [Compiled filter for dnsmasq](dnsmasq.servers), reusable in any [dnsmasq](https://thekelleys.org.uk/dnsmasq/doc.html) instance
